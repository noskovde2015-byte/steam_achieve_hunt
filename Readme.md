# Achieve Hunt (FastAPI + Steam API + RabbitMQ)

Сайт для тех, кто выбивает 100% достижений в играх в Steam. Показывает профили с платинами и очками, общий рейтинг, каталог игр с максимально возможными очками и детали по каждой игре. Данные подтягиваются из Steam автоматически, а тяжёлая синхронизация вынесена в фоновый воркер через RabbitMQ.

## Описание

Приложение позволяет:

- входить через Steam (OpenID),
- синхронизировать игры и достижения пользователя из Steam API,
- смотреть профиль игрока: очки, количество платин, список игр,
- смотреть рейтинг игроков за всё время, за месяц и за год,
- смотреть каталог игр с очками, которые можно получить за каждую игру,
- смотреть детали отдельной игры

Дополнительные особенности:

- **Steam OpenID и Steam API реализованы вручную** через `httpx`, без сторонних библиотек: проверка подписи ответа Steam, работа с эндпоинтами и обработка ошибок написаны с нуля
- **Продвинутая авторизация**: короткоживущий JWT access-токен в httpOnly-cookie и refresh-токен, который хранится в БД только в виде sha256-хэша, ротируется при каждом обновлении и действует в одном экземпляре на пользователя
- **Собственная формула очков**: редкие достижения стоят дороже, подробности ниже
- **Асинхронная синхронизация через RabbitMQ**: запрос на синхронизацию публикуется в очередь и сразу возвращает ответ, а отдельный воркер обрабатывает задачи
- **Устойчивость к ошибкам Steam**: приватные профили, игры без статистики и таймауты не останавливают синхронизацию остальных игр
- **Инкрементальный подсчёт**: количество платин и общие очки обновляются разницей между старым и новым значением, без пересчёта по всей таблице
- логирование в файл с ротацией и в консоль

## Как считаются очки

За каждое достижение начисляется:

```
очки = min(100, 100 / глобальный_процент_получения)
```

Чем реже достижение выбивают игроки по всему миру, тем больше очков оно приносит, максимум 100 за одно достижение. Очки за игру — сумма очков за полученные в ней достижения. Максимально возможные очки игры — сумма по всем её достижениям.

Глобальные проценты берутся из Steam (`GetGlobalAchievementPercentagesForApp`) и кэшируются в БД. Данные обновляются, если они старше 7 дней.

## Архитектура

Проект организован по принципу «один пакет на фичу»: у каждой функциональной области свои роутер, сервис и схемы.

```
Клиент ──> FastAPI (/api) ──> роутеры ──> сервисы ──> PostgreSQL
                │
                └── POST /api/game_info/sync ──> RabbitMQ (user_sync_queue)
                                                      │
                                        worker.py (consumer) ──> Steam API ──> PostgreSQL
```

Как работает синхронизация:

1. Клиент вызывает `POST /api/game_info/sync`.
2. API публикует задачу в durable-очередь `user_sync_queue` и сразу отвечает.
3. Воркер (`worker.py`) забирает задачу, ходит в Steam API и обновляет БД. Он запускается отдельным процессом, не через uvicorn.


Для RabbitMQ используется `aio-pika`: он асинхронный, в отличие от `pika`, который блокировал бы event loop.

## Развёртка

Перед началом использования необходимо клонировать репозиторий. Используйте команду в терминале:

```bash
git clone https://github.com/noskovde2015-byte/<НАЗВАНИЕ_РЕПОЗИТОРИЯ>.git
```

После этого перейдите в папку проекта:

```bash
cd <НАЗВАНИЕ_РЕПОЗИТОРИЯ>
```

Что понадобится заранее:

- Python и [Poetry](https://python-poetry.org/)
- Docker (для RabbitMQ)
- PostgreSQL, запущенный локально
- **Steam Web API Key**, получить его можно на https://steamcommunity.com/dev/apikey

После этого необходимо выполнить следующие шаги:

1. Установить зависимости:

```bash
poetry install
```

2. Создать базу данных в PostgreSQL:

```sql
CREATE DATABASE achieve_hunt;
```

3. Создать файл `.env` (переменные перечислены ниже).

4. Поднять RabbitMQ:

```bash
docker compose up -d
```

5. Применить миграции:

```bash
poetry run alembic upgrade head
```

6. Запустить API:

```bash
poetry run uvicorn app.main:app --reload
```

7. В отдельном терминале запустить воркер синхронизации:

```bash
poetry run python -m app.worker
```

После этого приложение готово к работе. Документация API доступна по адресу:

http://localhost:8000/docs

Панель управления RabbitMQ: http://localhost:15672 (логин и пароль `guest` / `guest`)

### Переменные окружения

Пример файла `.env`:

```env
# База данных
APP_CONFIG__DB__URL=postgresql+asyncpg://postgres:password@localhost:5432/achieve_hunt

# Steam
APP_CONFIG__STEAM__API_KEY=your_steam_api_key

# Авторизация (JWT)
APP_CONFIG__AUTH__SECRET_KEY=change_this_to_a_long_random_string
APP_CONFIG__AUTH__ALGORITHM=HS256
APP_CONFIG__AUTH__ACCESS_TOKEN_EXPIRE_MINUTES=30
APP_CONFIG__AUTH__REFRESH_TOKEN_EXPIRE_DAYS=7
```

Настройки RabbitMQ по умолчанию совпадают с `docker-compose.yaml` (`guest` / `guest`, порт `5672`), поэтому в `.env` их задавать не нужно.

Секретный ключ можно сгенерировать командой:

```bash
python -c "import secrets; print(secrets.token_urlsafe(48))"
```

### Состав Docker Compose

| Сервис | Описание |
|--------|----------|
| `rabbitmq` | RabbitMQ 3 с веб-интерфейсом, порты `5672` (AMQP) и `15672` (управление), данные в volume `rabbitmq_data` |

## Технологии

Проект написан с использованием:

- **Python** — основной язык
- **FastAPI** — фреймворк для API
- **SQLAlchemy (async)** — ORM для работы с базой
- **PostgreSQL** — основная база данных
- **Alembic** — миграции схемы
- **RabbitMQ + aio-pika** — очередь задач и асинхронный consumer
- **httpx** — клиент для Steam API и проверки OpenID
- **python-jose** — работа с JWT
- **Pydantic** — валидация данных и схемы запросов/ответов
- **Poetry** — управление зависимостями
- **Docker & Docker Compose** — контейнеризация инфраструктуры

## Возможности API

Все эндпоинты доступны под префиксом `/api`. Полный список со схемами — в Swagger UI (`/docs`).

| Метод | Путь | Описание | Доступ |
|-------|------|----------|--------|
| GET | `/api/auth/...` | Вход через Steam OpenID (login / callback) | публичный |
| POST | `/api/auth/refresh` | Обновление токенов (ротация refresh-токена) | по refresh-токену |
| POST | `/api/game_info/sync` | Поставить синхронизацию данных Steam в очередь | авторизованный |
| GET | `/api/profile/{steam_id}` | Профиль: имя, аватар, очки, платины | публичный |
| GET | `/api/profile/{steam_id}/games` | Игры пользователя (сначала платиновые, затем по прогрессу) | публичный |
| GET | `/api/leaderboard/` | Рейтинг за всё время (по платинам) | публичный |
| GET | `/api/leaderboard/monthly` | Рейтинг за месяц | публичный |
| GET | `/api/leaderboard/yearly` | Рейтинг за год | публичный |
| GET | `/api/games` | Каталог игр с постраничной выдачей (`page`, `page_size`) | публичный |
| GET | `/api/games/{appid}` | Детали игры: название, число достижений, максимум очков | публичный |
